# JARVIS OS

An offline AI desktop assistant inspired by Iron Man's JARVIS.

## Current Features

✅ Local AI (Qwen 2.5)
✅ Voice Input (Faster Whisper)
✅ Voice Output (Piper)
✅ Application Launcher
✅ Browser Automation
✅ LeetCode Integration
✅ DSA Workspace
✅ SQLite Memory Foundation
